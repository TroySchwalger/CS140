Fantastic freeform figs for four fizzy fruits

  • The action attribute that we used transfers the user to the set page when the action is made.
  • The method tag is what will occur when the action is taken. For this case it gets the new page. It declares if its post or get.
  • The difference between POST and GET is that GET includes what was inputted into the url. POST does not include the inputted things into the url.
  • For textboxes, you can set the value to something already inputted in when the page loads with the value field
  • For text areas, you set it by placing what you want between the tags
  • Select boxes has the name of each option in a value tag
  • Checkboxes can start with the boxes checked by having the value be yes.
  • Radio buttons can se the name of the button with the value attribute.
  • New form controls are url, email, tel, number, range, color, search, and some date and time ones. We didnt try out any of these new ones but we couldve for the eamil.
