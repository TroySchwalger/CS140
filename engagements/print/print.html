Platypics
  • It is important so that the page scales properly depending on how big the users screen is so everything fits.
  • By adding @media print at the end of the css we can adjust what gets printed or not.
  • Printers dont need to print the nav or links since you cant use those on paper. Also maybe some sizes need to be adjusted.
  • Some hard things to use when in phone mode is the nav when the screen is too small, the sidebar and main section collapse on each other, and it looks a bit big.
  • The breakpoint is about 400px wide before it collides. Or about 550px wide for the cards to be 2 wide.
  • We need the viewport tag so that it knows the size of the device it is displaying on.
  • The later tag overrides the previously stated tags.
  • By specifying the max width of the screen and using the @media thing we can change how the screen looks when the width is the same as a phone width.
  • On canvas the sidebar changes to the bottom of the phone to always be available. The classes are also neatly stacked on top of each other and the to do bar is hidden in the bottom nav. There are also added summaries and to do sections.
  • I chose my breakpoint to be 550px because that is when the pictures would split into a single column.
